DataNusa is a national statistics portal for Indonesia, built as plain static files with no build step and no network requests. It presents official-style headline figures — population 284.4 million, 2024 GDP of Rp22,139 trillion growing 5.03%, inflation, poverty at a record-low 8.47%, unemployment, and the trade balance — across six linked sections: a home page with key indicators, Economy (GDP structure donut, inflation and trade charts), Population (age pyramid and growth), Social welfare (poverty and unemployment trends), a searchable and sortable table of all 38 provinces, and an interactive data explorer that lets visitors pick an indicator, a chart type, and a year range. All charts are hand-drawn SVG generated by the site's own code, and the layout adapts from desktop down to a phone.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or hand the entry in with:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
